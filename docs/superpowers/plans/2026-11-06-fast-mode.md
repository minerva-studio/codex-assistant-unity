**Goal:** Match the model control card: discrete reasoning slider, model selector, separate Fast lightning and default-effort reset.

**Architecture:** Workspace owns the tier override; effective speed derives from it and the model's catalog default. The client forwards tier ids through thread/start, thread/settings/update and turn/start. CodexModelControl observes workspace state while attached. Its SliderInt changes only advertised reasoning levels; the lightning changes only Fast, and reset selects DefaultEffort. CreatePopup/PositionPopup share the overlay frame between the card and model search.
